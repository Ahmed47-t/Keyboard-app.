# KeyConnect ⌨️⚡ — لوحة مفاتيح هاتف كاملة الشاشة للحاسوب بنفس منطق KDE Connect

تطبيق ثنائي (**أندرويد** + **ويندوز**) مبني بنفس فلسفة الاكتشاف التلقائي والإقران المشفر في **KDE Connect**، لكنه **مُركّز ومُحسّن بنسبة 100% ليكون لوحة مفاتيح فقط** بأقل زمن استجابة ممكن (`< 0.5 ms` عبر USB و `< 2 ms` عبر Wi-Fi)، مع دعم كامل الوسائط المتاحة والتبديل التلقائي الذكي بينها.

---

## المزايا الأساسية

1. **شاشة إعداد البرنامج (Setup & Secure Pairing)**:
   - **اكتشاف تلقائي فوري** للحواسيب على الشبكة المحلية أو نقطة الاتصال (Hotspot) أو تقييد USB عبر `UDP 45820`.
   - **إقران فوري في ثانية واحدة عبر مسح رمز QR** الظاهر في برنامج الويندوز، أو **التحقق برمز أمان من 6 أرقام (PIN)** مطابق لمنطق KDE Connect.
   - **تشفير طرف لطرف (End-to-End AEAD)** باستخدام مفاتيح هوية `X25519` مع `HKDF-SHA256` وتشفير `ChaCha20-Poly1305`.

2. **كيبورد يملأ كامل شاشة الهاتف (Immersive Full-Screen Keyboard)**:
   - يخفي شريط الإشعارات وأزرار التنقل في أندرويد بالكامل ليستغل 100% من مساحة الشاشة.
   - **وضعان مدمجان مع التبديل الفوري بضغطة زر**:
     - **⌨️ كيبورد PC كامل الشاشة (6 صفوف)**: تخطيط **عربي 101 كامل مع التشكيل** + **إنجليزي QWERTY** + طبقة **Fn / F1–F12 / الميديا والأرقام**، وأزرار اللابتوب الكاملة (`Ctrl`, `Alt`, `Win ⊞`, `Shift`, `Esc`, `Tab`, `Del`, الأسهم)، مع دعم **اللمس المتعدد** للاختصارات (`Ctrl+C`, `Ctrl+V`, `Ctrl+Z`, `Alt+Tab`, `Win+D`)، وسحب إصبعك على زر المسافة لتحريك المؤشر بدقة!
     - **📱 وضع كيبورد الهاتف الأصلي والإملاء الصوتي**: يستدعي كيبورد هاتفك المعتاد (مثل Gboard أو الكتابة بالصوت 🎤 أو السحب) ويرسل كل حرف أو جملة أو مسح (`Backspace`) لحظياً للويندوز، مع شريط علوي لأزرار تحكم الويندوز.
   - **حقن Unicode مباشر في ويندوز (`KEYEVENTF_UNICODE` + Hardware Scancodes)**: أي حرف عربي تكتبه في الهاتف يظهر عربياً فوراً في اللابتوب حتى لو كانت لغة الكتابة الحالية في ويندوز هي الإنجليزية!

3. **دعم جميع وسائط الاتصال مع التبديل التلقائي الذكي (`Auto-Failover`)**:
   - **⚡ سلك USB (الأولوية القصوى — `< 0.5 ms`)**:
     - يعمل تلقائياً عبر جسر نفق ADB العكسي (`127.0.0.1:45821`) بمجرد توصيل السلك، **أو** بدون ADB عبر تفعيل **تقييد USB (USB Tethering / RNDIS)**.
   - **📶 شبكة Wi-Fi / Hotspot (`1–3 ms`)**:
     - اتصال مزدوج يجمع بين موثوقية `TCP_NODELAY (45821)` ومسار الضغطات السريع `UDP (45822)` لتفادي أي تأخير.
   - **🔵 البلوتوث المباشر (`3–8 ms` بدون راوتر أو إنترنت)**:
     - **Bluetooth Classic RFCOMM** عبر مقبس Winsock2 الأصلي في ويندوز (`AF_BTH`) دون الحاجة لأي تعريفات خارجية.
     - **وضع Bluetooth HID العتادي (Android 9+)**: يجعل الهاتف يعمل كلوحة مفاتيح بلوتوث فيزيائية قياسية حتى في شاشة قفل الويندوز أو الـ BIOS دون تشغيل أي برنامج على الحاسوب.

## هيكل المشروع والأدوات المستخدمة

| المجلد | الوصف والتقنيات |
| :--- | :--- |
| `windows-host/` | **تطبيق سطح المكتب لويندوز 10/11** مبني بلغة **Rust** + واجهة `eframe/egui` الأصلية الخفيفة + `windows-sys` (`SendInput`, `MapVirtualKeyW`, Winsock2 `AF_BTH` Bluetooth RFCOMM) + `tokio`. |
| `android-app/` | **تطبيق أندرويد الأصلي** مبني بلغة **Kotlin 2.0** + **Jetpack Compose (Material 3)** + CameraX/MLKit لمسح QR + BouncyCastle للتشفير المتوافق + `BluetoothSocket` & `BluetoothHidDevice`. |
| `web-preview/` | **محاكي حي وتطبيق ويب مرافق** بـ Node.js + WebSockets يحاكي شاشة الهاتف وشاشة اللابتوب مع تشفير `ChaCha20-Poly1305` وتجربة فصل/توصيل الوسائط مباشرة. |
| `.github/workflows/` | خط بناء سحابي تلقائي (**GitHub Actions**) يبني ويختبر وينتج ملفَي `KeyConnect-Windows-x64.exe` و `KeyConnect-Android.apk` تلقائياً. |
| `Start-KeyConnect-Windows.bat` | **مشغّل فوري لويندوز بدون تثبيت أي أدوات**: يبني ويشغّل مستقبل `Win32 SendInput` خلال ثانية واحدة بأدوات ويندوز المدمجة لتجربته فوراً مع هاتفك عبر Wi-Fi أو سلك USB. |
| `ci/build-release.yml` | ملف خط البناء السحابي (**GitHub Actions**) لتوليد ملفَي `KeyConnect-Windows-x64.exe` و `KeyConnect-Android.apk` تلقائياً في السحابة. |
| `docs/` | التوثيق الهندسي الكامل (`ARCHITECTURE.md`) ومواصفات البروتوكول المشفر (`PROTOCOL.md`). |

## كيف تجرّبه فوراً على اللابتوب وهاتفك؟ (3 طرق)

### الطريقة 1: تجربة فورية خلال 10 ثوانٍ بدون تثبيت أي برامج تطوير!
1. حمّل المشروع كملف مضغوط (**Code -> Download ZIP**) على لابتوب الويندوز وفك الضغط عنه.
2. اضغط مرتين على الملف **`Start-KeyConnect-Windows.bat`** (يستخدم مترجم `.NET` المدمج مسبقاً في كل نسخ ويندوز 10 و11 بدون الحاجة لتثبيت أي شيء).
3. ستفتح لك نافذة برنامج **KeyConnect** على ويندوز وبها رابط مباشر (يدعم **Wi-Fi** كما يدعم **سلك USB** بمجرد تفعيل "تقييد USB / USB Tethering" من الهاتف).
4. افتح الرابط الظاهر في متصفح هاتفك واضغط **`⛶ ملء الشاشة`** — أي حرف عربي أو إنجليزي أو اختصار تكتبه في هاتفك سيُكتب فوراً في ويندوز!

### الطريقة 2: توليد ملفَي التثبيت المستقلين (`.apk` للأندرويد + `.exe` لويندوز) سحابياً عبر GitHub Actions
بدون تثبيت Android Studio أو Rust على حاسوبك:
1. في مستودعك على GitHub، أنشئ ملفاً جديداً بالمسار `.github/workflows/build-release.yml` وانسخ بداخله محتوى الملف الجاهز `ci/build-release.yml`.
2. افتح تبويب **Actions** في مستودعك، وستجد GitHub يبني التطبيقين تلقائياً وينتج في قسم **Artifacts**:
   - **`KeyConnect-Windows-x64.exe`** (برنامج ويندوز الكامل بـ Rust مع دعم Bluetooth RFCOMM و ADB USB و QR).
   - **`KeyConnect-Android.apk`** (تطبيق الأندرويد الأصلي بـ Kotlin/Compose لتثبيته على الهاتف).

### الطريقة 3: البناء المحلي من المصدر

#### 1) بناء برنامج ويندوز (`windows-host`)
يتطلب تثبيت [Rust](https://rustup.rs) على ويندوز:
```powershell
cd windows-host
cargo test
cargo build --release
# ستجد الملف التنفيذي الجاهز في:
# windows-host\target\release\keyconnect-host.exe
```

#### 2) بناء تطبيق أندرويد (`android-app`)
افتح مجلد `android-app` في **Android Studio** واضغط **Run**، أو عبر سطر الأوامر (JDK 17 + Gradle 8.9):
```bash
cd android-app
gradle testDebugUnitTest assembleRelease
# ستجد ملف الـ APK الجاهز في:
# android-app/app/build/outputs/apk/release/app-release.apk
```

## خطوات الاستخدام السريع (أقل من 10 ثوانٍ)

1. شغّل **`KeyConnect-Windows-x64.exe`** على اللابتوب (سيظهر لك رمز QR وحالة وسائط النقل).
2. افتح تطبيق **KeyConnect** على هاتفك الأندرويد:
   - إما اضغط **"إقران فوري برمز QR"** ووجّه الكاميرا نحو شاشة اللابتوب،
   - أو اضغط على اسم حاسوبك الظاهر تلقائياً في القائمة وأكّد رمز الـ PIN المكوّن من 6 أرقام على اللابتوب.
3. ينفتح أمامك فوراً **الكيبورد بكامل الشاشة** — اكتب بالعربية أو الإنجليزية أو استخدم الاختصارات وسينتقل كل حرف لحظياً إلى اللابتوب!
