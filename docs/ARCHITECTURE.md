# المعمارية الهندسية لنظام KeyConnect (System Architecture)

صُمّم **KeyConnect** بنفس فلسفة الاكتشاف والإقران المشفر في **KDE Connect**، مع إعادة هندسة كاملة لطبقة النقل والإدخال لتكون **مخصصة حصرياً للكيبورد** بأقل زمن استجابة ممكن (`< 0.5 ms` عبر USB و `< 2 ms` عبر Wi-Fi).

---

## 2. كيف تعمل الوسائط الثلاثة والتبديل التلقائي (Multi-Transport Failover)

1. **وسيط USB (الأسرع والأكثر استقراراً — `< 0.5 ms`)**:
   - **جسر ADB التلقائي (`usb_adb.rs`)**: يراقب برنامج الويندوز منفذ USB تلقائياً في الخلفية؛ وبمجرد توصيل الهاتف ينفّذ نفق عكسي صامت (`adb reverse tcp:45821 tcp:45821`) بحيث يتصل الهاتف بـ `127.0.0.1:45821` عبر سلك الـ USB مباشرة دون الحاجة لراوتر.
   - **تقييد USB (`USB Tethering / RNDIS`)**: إذا فعّل المستخدم "تقييد USB" من إعدادات الهاتف دون ADB، يكتشف البرنامج واجهة الشبكة السلكية الافتراضية (`192.168.42.x` / `172.20.x.x`) ويصنفها كاتصال USB مباشر فائق السرعة.

2. **وسيط Wi-Fi (لاسلكي فائق السرعة — `1–3 ms`)**:
   - **الاكتشاف التلقائي (`UDP 45820`)**: يرسل الهاتف والكمبيوتر نبضات اكتشاف عبر الشبكة المحلية ونقاط الاتصال المحمولة (Hotspot).
   - **النقل الهجين (`TCP_NODELAY 45821` + `UDP 45822`)**: تُرسل حزم الإقران والنصوص الطويلة عبر TCP الموثوق مع تعطيل خوارزمية Nagle، بينما تُرسل ضغطات المفاتيح الفردية عبر مسار UDP السريع لتفادي أي تأخير ناتج عن Head-of-Line Blocking.

3. **وسيط Bluetooth (بدون إنترنت أو شبكة — `3–8 ms`)**:
   - **بروتوكول RFCOMM الأصلي (`bluetooth_rfcomm.rs`)**: يستخدم مقبس Winsock2 الأصلي في ويندوز (`AF_BTH` / `BTHPROTO_RFCOMM`) مع تسجيل خدمة SDP بالمعرّف الموحد `8e7f1a20-4b9c-4d1e-9a6b-5c3d2e1f0a9b` دون الحاجة لأي تعريفات خارجية.
   - **وضع Bluetooth HID العتادي (`BluetoothHidController.kt`)**: يتيح للهاتف الظهور لويندوز كلوحة مفاتيح بلوتوث فيزيائية قياسية تعمل حتى في شاشة قفل ويندوز قبل تسجيل الدخول.

4. **منع تكرار الحروف أثناء التبديل (`Sliding Window Deduplicator`)**:
   - يحمل كل حدث ضغطة زر رقماً تسلسلياً (`event_id`). عند نزع سلك الـ USB أثناء الكتابة، ينتقل `ConnectionOrchestrator` فوراً إلى Wi-Fi أو Bluetooth خلال أقل من `50ms` ويعيد إرسال أي ضغطة لم يصل تأكيدها، بينما يتكفل `HostHub` في ويندوز بتجاهل أي رقم تسلسلي سبق تنفيذه.
